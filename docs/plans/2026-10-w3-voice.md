# W3 · Hybrid voice: test what the phone already does, download only if needed

2026-10-17 · Diátaxis: Explanation · Part of `2026-10-roadmap.md` · Status: plan, awaiting Y4NN's review.
Y4NN 2026-10-17: "it should be hybrid: if the phone's dictation works well during the setup test, tell
the user there is no need for the pack; otherwise help them set it up"; "5 more serious phrases";
"the three levels are coherent but must be made precise".

## 1. Engines

| Id | Engine | How the app gets text | Download | Where the voice goes |
|----|--------|-----------------------|----------|----------------------|
| A | Browser on-device recognition | `SpeechRecognition` with `processLocally: true`, only when `available()` answers `"available"` for the user's language | none | stays on the phone |
| B | Keyboard dictation (Gboard, Apple) | the user taps the keyboard's microphone; the text lands in the field | none | the keyboard's own policy, outside the app; said once in the setup |
| C | WiseMoney voice pack | Whisper tiny (multilingual, q8) through transformers.js 4.3.0, ONNX runtime from our origin | about 70 MB once (measured on desktop, 2026-10-16) | stays on the phone |

The browser's cloud recognition is excluded (ADR-0014). Preference order: A, then B, then C.

## 2. The five test phrases

Read correctly by the reader v2 when written correctly (checked 2026-10-17), so a miss is the engine's:

| # | Said | Amount | Direction | Note must contain | Trap |
|---|------|--------|-----------|-------------------|------|
| 1 | Essence moto deux mille cinq cents | 2500 | — | essence | thousands with hundreds |
| 2 | Crédit Orange mille francs | 1000 | — | orange | brand, "francs" |
| 3 | Loyer quatre-vingt-dix mille | 90000 | — | loyer | quatre-vingt-dix |
| 4 | Salaire cent soixante-quinze mille | 175000 | income | salaire | soixante-quinze, income |
| 5 | Awa m'a remboursé douze mille cinq cents | 12500 | income | awa | name, "m'a remboursé" |

A phrase **passes** when the amount is exact, the direction matches (none expected on 1–3), and the note
contains the word (accents and case ignored). Phrases appear one at a time; the user may say "passer".

## 3. Thresholds (initial, calibrated on the first real phones, then fixed in code with a comment)

- An engine **qualifies** with at least **4 of 5** phrases passed.
- A and C also need a **median time from end of speech to text ≤ 3 s**. B is not timed: the app cannot
  see when the user starts speaking.
- C preflight: free storage ≥ **200 MB** (`navigator.storage.estimate`); on `saveData` or a cellular
  connection the download asks for confirmation ("Préférez le Wi-Fi"); `deviceMemory` < 2 GB, when the
  browser reports it, warns that the pack may be slow.

## 4. Decision (a pure function, tested)

```
probe → A available?  yes → test A → qualifies → engine A, done
                       no / fails ↓
        test B (or "Mon clavier n'a pas de micro") → qualifies → engine B, done
                       fails / skipped ↓
        offer C → preflight → download → test C → qualifies → engine C, done
                                               fails → keep B if B passed ≥ 3, else "keyboard
                                               typing", and offer to delete the pack
```

`chooseVoiceEngine(probe, scores)` takes the capability probe and the per-engine scores and returns the
engine and the reason shown to the user; same inputs, same answer.

## 5. What the mic icon does after setup

- A: records in the app. B: opens the keyboard and points to its microphone (as today). C: records in
  the app and transcribes on the phone. Before any setup: today's behaviour, plus "Configurer la voix".

## 6. What is stored, and where

`localStorage` `wisemoney.voice.profile.v1`: engine, the five pass/fail results and times, date, app
version, model revision. Nothing about money, no audio, no transcript. The pack lives in the Cache API
under the app's own name. Settings › Voix: "Refaire le test", "Supprimer le pack (70 Mo)".
The test is offered again when the browser version or the pinned model revision changes.

## 7. Engineering

- `VoiceEngine` interface (`probe`, `listen(phrase)`, `dispose`) with three implementations; engine C
  reuses `src/voice/lab/whisperLab.ts`, moved out of the lab.
- Model pinned to a Hugging Face revision (commit id), not "main", so every phone runs the same files;
  files fetched one by one, so an interrupted download resumes at the next file.
- The setup is a sheet of four steps (probe, test, decision, done) reachable from the mic icon and
  Settings › Voix; every string through i18n; help topic `transactions` follows.
- Tests: the decision function (every branch), the phrase scoring, the probe on fake capabilities; a
  smoke path with engine B simulated by filling the field.

## 8. Order

1. ADR-0014 amendment: the hybrid decision, the pack as an optional third engine.
2. Scoring, decision function, profile store (no screen).
3. The setup sheet with engines A and B.
4. Engine C: preflight, pinned download, test, delete.
5. Settings › Voix, help topic, smoke.

The `/lab/voice` page goes away at step 4.
